# Noto PDF report fonts

These static Regular fonts are served locally only when a family exports an attendance PDF. Latin and Hindi glyphs are embedded as subsets; the browser never requests a third-party font service.

Source: official [notofonts/noto-fonts](https://github.com/notofonts/noto-fonts) repository, fetched 7 November 2026:

- `hinted/ttf/NotoSans/NotoSans-Regular.ttf`
- `hinted/ttf/NotoSansDevanagari/NotoSansDevanagari-Regular.ttf`
