# Official class and school attendance reports

7 November 2026. [Founder checklist](../../public/qa/office-attendance-reports-checklist.md) · [Stable Production](https://kids-corner-erp-frontend.vercel.app/login).

## Product boundary

Reports & Analytics gives actual School Admin/Principal a verified school, academic year, month, whole-school/class and optional section scope. The Attendance register links to this reader. Existing Finance report access does not become an attendance-report permission. Both monthly and academic-session summaries use the approved daily-v1 weighting: Present/Late 1, Half Day 0.5, Leave/Absent 0, excluding school-closed pupil-days. The combined percentage is total earned pupil-days divided by total eligible working pupil-days; it is not the average of individual pupil percentages.

A pupil-day is one pupil's eligible day. Counts across multiple pupils are labelled as pupil-days, rather than claiming they are distinct school calendar dates. Admission, promotion, audited class/section moves and verified withdrawal bound historical eligibility. Unmarked workdays, missing calendars, contradictory marks or uncertain enrollment/placement withhold the official percentage. Uncertain attribution remains conservatively included for review instead of silently removing a pupil from a class denominator. Valid closed-only periods and not-yet-started enrollments do not invent a zero rate.

Existing family APIs keep their public contract and actual student/linked-child restrictions while delegating to the common private calculation. Office authorization requires the current active profile school, an actual school_admin/principal role, live native session and the existing MFA policy; metadata labels and a global-only role do not substitute for office permission. Context and report reads recheck access after lock waits. Office output contains aggregate counts and scope labels, with no peer pupil names or contact details.

Year/month/class/section preferences are session-only and bound to the verified account, UI role and school; report data is not cached there. Scope/auth changes cancel obsolete reads and exports. The PDF includes the selected school/class/year/month, both weighted summaries, coverage, formula, calendar revision and IST cutoff/generation time. It revalidates the displayed source before and after local generation; no hosted/public PDF link or provider send is created. It is a dated snapshot, not a digitally signed certificate, and a downloaded file cannot be remotely revoked.
